## Scope

This is the edition catalogue only, not the complete Quran text corpus. The upstream repository contains a very large dataset (GitHub reports approximately 4.26 million KB repository size), so importing every file into this application's Git history would be impractical. Quran edition payloads should be mirrored in staged, verified batches or consumed from the versioned jsDelivr endpoints, with source metadata preserved.

No transformation or normalization has been applied to the catalogue.
